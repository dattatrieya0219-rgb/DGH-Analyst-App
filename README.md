# Auto Data Analyst PRO

A self-service data analysis web app built with **Python** and **Streamlit**. Upload a CSV file and get cleaning, exploratory analysis, statistics, a basic ML model, and a downloadable report — without writing any code.

**Live App:** https://dgh-analyst-app.streamlit.app

---

## Features

| Tab | What it does |
|-----|--------------|
| 1. Upload | Upload any CSV file and preview the data |
| 2. Cleaning | Handle missing values, remove duplicates, fix data types |
| 3. EDA | Summary statistics and charts to explore the data |
| 4. Statistics | Descriptive statistics and correlations |
| 5. ML Modelling | Train a simple machine learning model on the data |
| 6. Report Export | Download the analysis as a report |

## Tech Stack

- **Python** — pandas, NumPy, matplotlib
- **Streamlit** — web app framework
- **Streamlit Community Cloud** — deployment

## Run Locally

```bash
git clone https://github.com/dattatrieya0219-rgb/DGH-Analyst-App.git
cd DGH-Analyst-App
pip install -r requirements.txt
streamlit run analyst_pro_app.py
```
